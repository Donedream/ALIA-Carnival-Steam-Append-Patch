# ALIA's CARNIVAL! Steam 版 Append 补丁

> 让 **Steam 中文版**也能玩到官方日文版的 5 条追加剧情（append1~5），
> 并可选提供「半脱」换装功能。

---

## 这是什么

《ALIA's CARNIVAL!》在发售多年后推出过 5 个追加剧情补丁（append1~5），
但这些补丁只面向**日本原版**用户，且仅以 `.exe` 安装包形式发布。

Steam 版因为引擎和资源结构不同，**直接放入这些补丁不会生效**——
主菜单会出现 append 入口，但点进去是空白。

本项目做了三件事：

1. 从官方 `.exe` 中提取出 `patch_appendN.xp3`，并按 Steam 版引擎的要求
   **重新组织**，使 5 条追加剧情可以正常加载；
2. 移植并整理了剧情的中文翻译，以及**入场标题图**的中文本地化；
3. 将官方后续推出的「半脱（裸ニーソ）」换装功能**独立成可选包**，
   不影响不想要它的玩家。

最终将文件整理成 **6 个（+1 个可选）**。

## 快速安装

1. 关闭游戏
2. 打开游戏目录：
   ```
   C:\Program Files (x86)\Steam\steamapps\common\aliascarnival
   ```
3. 把 `patch_append1~5.xp3` 和 `patch_append6.xp3` 复制进去
4. 想要换装功能，再复制 `patch_append9.xp3`
5. 启动游戏

**完整说明、排错、自制方法见 [安装说明.md](安装说明.md)。**

## 验收标准

两个包是**各司其职**的，功能不会互相替代：

| 安装内容 | append 图标 | 五个角色按钮 | 中文剧情 | 中文标题图 | 换装开关 |
|---|:---:|:---:|:---:|:---:|:---:|
| **只装基础包**（1~6） | ✅ | ✅ | ✅ | ✅ | ❌ |
| **基础包 + 换装包**（1~6、9） | ✅ | ✅ | ✅ | ✅ | ✅ |
| **只装换装包**（仅 9） | ❌ | ❌ | — | — | ⚠️ |

**关键说明：**

- **换装包不提供 append 功能**。它里面没有 `scnselect.tjs`（按钮注册表），
  所以单独安装不会出现 append 图标，也不会出现五个角色按钮。
- 只装换装包时，理论上设置界面仍可能出现换装开关（该包自带 UI 定义与注册脚本），
  并可能影响基础游戏的角色服装表现——**但这个组合未经过实测**，
  仅把换装包当作独立功能使用时请自行验证。
- 正确用法是**以基础包为前提**，换装包只作为附加功能。

## 包里有什么

```
patch_append1~5.xp3    官方内容素材（5 条剧情线）
patch_append6.xp3      自建修复层：注册表 + 中文剧本 + 翻译 + 标题图
patch_append9.xp3      可选：半脱换装（77 个姿势定义 + 1247 张素材）
```

修复层只做"让引擎读得懂"和"换成中文"，**不覆盖任何原始文件**。
标题图本地化利用游戏内置的 `_reimg()` 机制，按语言自动切换，
日文环境下仍显示官方原图。

## 后续计划

当前版本仍属早期，以下内容**尚未完善**：

### 尚未支持

- **暂无繁体中文版**。补丁只做了简体中文；繁体环境下会回退到日文原图与日文原文。
- **部分文本可能仍有日文残留**，个别条目翻译未经校对。

### 仍在优化

- **append 中文标题图目前是临时版本**。
  现有的 11 张标题图是临时制作的，存在以下问题：
  - 字体与原版美术字不完全一致
  - 位置/间距可能有细微偏差
  - 译文措辞可能不够准确
- 后续会持续优化标题图的排版、字体与译文质量。
- 剧情翻译由 AI 生成（原作者使用 Gemini），可能存在措辞生硬或误译，
  欢迎反馈但不保证及时修正。

### 计划中

- 繁体中文标题图与文本
- 标题图美术质量提升
- 翻译质量校对

## 关于本项目的制作

**本项目的实现依托于 DeepSeek Harness（一只可爱的大肥鱼）完成。**

具体技术路径：

1. **问题定位** —— 通过逐项对照实验，确认 Steam 版不识别官方补丁的原因是
   注册表路径（`scnselect.tjs`）与文本编码（Shift-JIS vs UTF-16LE）不匹配；
2. **格式逆向** —— 解析 `.xp3` 归档结构（索引位置、段表、`adlr` 校验、压缩方式），
   从零编写打包器 `xp3pack.py`；
3. **资源重组** —— 把官方素材、翻译文本、标题图重新组织成 Steam 版可读的归档；
4. **机制复用** —— 发现并利用引擎内置的 `_reimg()` + `imagenamemap.txt`，
   实现标题图按语言自动切换，而无需修改任何原始文件；
5. **文档整理** —— 安装指南、排错手册与技术说明。
